About this project

PROJECT NOTES

FLAT / FORM is an independent ai.ro project that interprets specific official IKEA editions as interactive 3D assembly guides. It is not affiliated with or endorsed by IKEA.

These guides supplement, not replace, the official manual. The geometry is illustrative and does not verify fit, wall attachment, or load.

Use the guide

  1. Pick your edition

    Choose the exact model and open its official manual.

  2. Build step by step

    Read the instructions and warnings, inspect parts, and replay placements.

  3. Inspect the finished model

    Orbit your selected configuration and return to the previous instruction.

How it’s built

  1. Pin the official manual

    Record the edition, checksum, and page evidence.

  2. Model and check

    Reconcile the inventory, model original geometry, and test steps and placements.

  3. Build and render

    Vite generates the HTML catalog. Browser JavaScript reads the deterministic assembly timeline, and Three.js renders the assembly.

Numbered instructions and official manual links still work when 3D or local previews are unavailable.
